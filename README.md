# CoffeeSync - Sistema POS para Cafeterías

CoffeeSync es un sistema de Punto de Venta (POS) web diseñado para cafeterías. Combina una arquitectura robusta con una interfaz de usuario (UI/UX) moderna e intuitiva.

## Características Principales

• **Seguridad por Roles (RBAC):** Autenticación mediante cookies con accesos restringidos para `Administrador` (gestión del catálogo) y `Barista` (operación de ventas).
• **Flujo de Ventas Dinámico:** Sistema de carrito de compras manejado en sesión para una creación de órdenes rápida y fluida.
• **Cálculo de Pagos:** Módulo de cobro automatizado con cálculo de cambio en tiempo real.
• **Tickets de Compra:** Generación de comprobantes de pago optimizados para impresoras térmicas (listos para imprimir o guardar como PDF).
• **Gestión de Catálogo:** Operaciones CRUD completas para categorías y productos con control de disponibilidad.
• **Diseño UI/UX:** Interfaz responsiva estilizada con una paleta de colores orgánica, componentes personalizados y tablas de datos avanzadas.

## Stack Tecnológico
• **Backend:** C#, ASP.NET Core MVC
• **Base de Datos:** SQL Server, Entity Framework Core
• **Frontend:** Vistas Razor, HTML5, CSS, Bootstrap
• **Herramientas Adicionales:** jQuery, AJAX, DataTables, Select2 y Bootstrap Icons
